# App Review launch crash — September 22, 2026

## Verified rejection and cause

App Store Connect rejected version 1.0 (3) under Guideline 2.1(a), reporting a
launch crash on iPad Air 11-inch (M3), iPadOS 27.0. Submission ID:
`e673c879-964d-41dd-a333-5df1475d6e24`. Manual release remains selected.

Both attached crash reports stop in UIKit at
`___UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption_block_invoke`
with `EXC_BREAKPOINT` / `SIGTRAP`, before game initialization. The app image UUID
`A351196B-C60C-3CE6-85E6-4938774C32B8` matches the retained build-3 dSYM;
its app frame symbolicates to `main`. System frames are already symbolicated.
Raw reports are retained privately under ignored `ios/ReviewLogs/2026-09-22/`.

Apple requires apps built with the iOS 27 SDK to adopt the scene lifecycle:
[Apple migration guide](https://developer.apple.com/documentation/uikit/transitioning-to-the-uikit-scene-based-life-cycle).
The project had Capacitor 8.5.0, including `SceneDelegateProxy`, but retained
the old AppDelegate-only application template.
